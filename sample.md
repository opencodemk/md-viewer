# Markdown Viewer Demo

Selamat datang ke **Markdown Viewer**! App ni dibina guna Electron dan `marked`.

## Features

- Buka fail `.md` guna `Ctrl+O`
- **Table of Contents** auto-generate dari heading
- Dark theme (VS Code style)
- Syntax highlighting untuk code blocks

### Code Example

```python
def hello():
    print("Hello from Markdown Viewer!")
```
